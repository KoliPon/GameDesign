# V0.2.0 進階手勢辨識

## 檔案

- `GestureChain.cs`：加入補點、主軸校正、保角平滑及排他分類。
- `GestureDrawer_V0.2.0.cs`：滑鼠／觸控軌跡在平滑前補齊大間隔。
- `UDPReceiver_V0.2.0.cs`：UDP 軌跡通過最小點數檢查後、重採樣前補齊大間隔。
- `ShapeNormalizer.cs`：共用的補點、PCA 主軸校正、保角平滑與角點計數工具。

## 三項改善

### 1. 開口與缺點

每對連續點若距離大於 `Gap Fill Maximum Segment Length`，系統會在線段中插入等距點。預設為 `10`，請依實際畫布或 IMU 座標比例調整：較小值可修補較小開口，但會產生更多點。

補點只會連接已連續記錄的相鄰點，不會將手勢首尾強制連起來，避免把未完成圖形誤當封閉圖形。

### 2. 歪斜與抖動

`GestureChain_V0.2.0` 會先以 PCA 計算主軸，將軌跡旋轉為水平，再做輕量平滑。轉角達 45 度以上的點會保留，因此三角形及正方形的角不會被一般抖動平滑掉。

可由 Inspector 的 `Normalization Smoothing` 調整強度；建議從預設 `0.35` 開始。過高的值可能讓小型三角形的角變鈍。

### 3. 避免誤判正方形

V0.2.0 固定採用 `Circle → Triangle → Square → One Dollar` 的順序：

| 圖形 | 條件 |
| --- | --- |
| Circle | roundness > 0.50、角點 <= 1、首尾開口／路徑長 < 0.9 |
| Triangle | sharpness > 0.45、角點 2–4 |
| Square | angularity > 0.50、長寬比 > 0.60 |

正方形僅在圓形與三角形都不成立後才會被採用。未符合這些幾何條件的結果才會交給既有 One Dollar Recognizer 作為後備。

## 安裝

這些是替換版本；Unity 專案中不要同時啟用同一元件的 V0.1.0 與 V0.2.0 檔案，以免發生重複類別。先備份舊檔，再以 V0.2.0 檔案替換既有 `GestureDrawer.cs`、`UDPReceiver.cs` 與 `GestureChain.cs`；保留 `ShapeNormalizer.cs` 在同一個 `Assets` 編譯範圍。

## 驗證清單

- 畫快速圓形、含輕微開口的圓形，確認結果為 Circle。
- 畫旋轉三角形並確認三個轉角仍可辨識為 Triangle。
- 畫旋轉正方形並確認結果為 Square。
- 畫未封閉或無法辨識的筆劃，確認不會因補點而被強制封閉。
- 在 Console 觀察 `[V0.2.0]` 日誌中的圓度、角點與周長比，依畫布比例微調 Inspector 參數。
