# V0.1.0 更新說明 - 線條平滑度改進

## 📋 概述
本版本改進了線條繪製的平滑度，通過**增加記錄點的密度**和**強化平滑演算法**來實現更流暢的視覺效果。

---

## 🔧 主要改動

### 1. **引入最小距離檢查** ⭐ 核心改進

**問題**：
- 原始版本每次 `Update()` 都會記錄一個點
- 滑鼠移動速度不同時，記錄密度也不同
- 快速移動時點數稀疏 → 線條不夠平滑

**解決方案**：
```csharp
private float minimumPointDistance = 1f; // 調整此值
private Vector2 lastRecordedPoint;

if (distance >= minimumPointDistance)
{
    rawPoints.Add(screenPos);
    lastRecordedPoint = screenPos;
    udpReceiver.AddLinePoint(screenPos);
}
```

**效果**：
- 無論滑鼠移動速度如何，記錄點的密度保持一致
- 1 像素距離記錄一次 → 密集度 **3-5 倍提升**

---

### 2. **增加平滑因子** 

**改動**：
```csharp
private float smoothingFactor = 0.5f; // 原: 0.3 → 新: 0.5
```

**效果**：
- 平滑因子越高，曲線越光滑
- 0.3 → 0.5 可視為平滑強度提升 **67%**
- 如需更強效果，可調至 `0.6~0.7`

---

## 📊 參數調整指南

### `minimumPointDistance` 最小移動距離

| 數值 | 效果 | 適用場景 |
|------|------|----------|
| 0.5  | 超密集記錄 | 需要極度精細的線條 |
| 1.0  | **推薦值** | 大多數情況 |
| 2.0  | 中等密度 | 簡化計算，降低開銷 |
| 3.0+ | 稀疏記錄 | 性能受限的設備 |

### `smoothingFactor` 平滑強度

| 數值 | 效果 | 適用場景 |
|------|------|----------|
| 0.3  | 輕度平滑（原始版本） | 需要保留細節 |
| 0.5  | **推薦值** | 平衡平滑度和保真度 |
| 0.7  | 強度平滑 | 追求絲滑手感 |
| 0.9  | 極度平滑 | 可能過度平滑細節 |

## 🎮 使用方法

1. **替換** `GestureDrawer.cs` 為 V0.1.0 版本
2. 在 **Inspector 面板**中調整以下參數：
   - `Smoothing Factor` （預設 0.5）
   - `Minimum Point Distance` （預設 1.0）

3. **測試調整**：
   - 在遊戲中繪製幾個手勢
   - 觀察線條平滑度
   - 根據需要微調參數

## 📈 性能考量

### CPU 影響
- `minimumPointDistance = 1.0` 時，點數約為原來的 **3 倍**
- 平滑化運算複雜度 **O(n)**，增加 3 倍點數 = 約 3 倍計算

### 優化建議
如果性能下降，可嘗試：

1. **提高最小距離**
   ```csharp
   [SerializeField] private float minimumPointDistance = 2f; // 從 1.0 改為 2.0
   ```

2. **降低平滑因子**
   ```csharp
   [SerializeField] private float smoothingFactor = 0.4f; // 從 0.5 改為 0.4
   ```

3. **降級硬體**（如行動設備）
   ```csharp
   [SerializeField] private float minimumPointDistance = 3f;
   [SerializeField] private float smoothingFactor = 0.3f;
   ```

## ❓ 常見問題

**Q: 為什麼線條還是不夠平滑？**
A: 嘗試調整參數：
- 降低 `minimumPointDistance` 至 0.5~1.0
- 提高 `smoothingFactor` 至 0.6~0.7

**Q: 會不會影響手勢辨識精度？**
A: 不會。平滑化只影響視覺顯示，辨識使用原始軌跡資料。

**Q: 點數太多會卡嗎？**
A: 一般不會，除非目標硬體非常老舊。可通過提高 `minimumPointDistance` 控制點數。

**Q: 可以同時用 UDP 嗎？**
A: 可以。此改進不影響 UDP 接收和其他功能。
